## New anti-patterns

1. **Symlinking shared agent contracts into a working tree that has feature branches.** Unmerged or program-only rules reach other projects' by-hand runs. → P-29
2. **A brief whose security or risk rows rely on a constant that its own design sets differently** (0700 vs 0555), approved at CP2 without cross-checking. → P-30
3. **Trusting a single-OS live smoke for a permission or location property.** → P-31
4. **Measuring an agent's writes against an older reference** (the snapshot) instead of a baseline taken just before it: the agent is blamed for others' changes, and a resume can launder its writes. → C-37
5. **"Blind" reviewers run in sequence, with the first's verdict persisted where the second can read it.** → C-39
6. **A session accepting a deviation that raises a version floor or changes a security property.** → P-34
7. **A probe correction left in the step log, with no owning step:** the docs keep the false claim. → P-32
8. **A test clause that can never fail** ("untouched" when the code rewrites identical content). Kill the mutant, but also check each assertion can go RED.
9. **Copying test helpers verbatim into a new test file, or running real git outside the designated files.** → C-42
10. **Launching a builder in the same minute as the decision it implements**, before the operator has confirmed scope. → P-35
11. **A git action after merge (switching branches) without asking.** → P-38
